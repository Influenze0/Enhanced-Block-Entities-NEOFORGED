This mod is an unofficial fork of the Enhanced Block Entities mod for the previously unsupported modloader, Neoforge.

Link to the original **[mod](https://github.com/FoundationGames/EnhancedBlockEntities)**.

Link to the original **[author](https://modrinth.com/user/FoundationGames)**.

The mod allows for the configuration and optimization of block entity rendering using a more modern approach.

The mod is compatible with the Sodium mod, which can be found at https://modrinth.com/mod/sodium/versions?l=neoforge
